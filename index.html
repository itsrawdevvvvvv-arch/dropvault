DropVault

Drop it. Link it. Done.

Drag any file here — it commits straight to your GitHub repo and you get a clean, shareable link in seconds. No terminals, no setup.

1 Connect your GitHub (one time)

DropVault uploads using your own GitHub account. To keep it secure, paste a token once — it's stored only in this browser and never leaves your device except to GitHub itself.

  1. Click Create a token on GitHub (opens with the right permission pre-selected).
  2. Scroll down, click Generate token, then copy the ghp_… value.
  3. Paste it below and hit Save & verify.
Your files land in a public repo, so anything you upload gets a public link. Don't drop private or sensitive documents.
